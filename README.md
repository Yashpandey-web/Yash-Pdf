# Yash PDF



 Enjoy Here :  https://yashpandey-web.github.io/Yash-Pdf/
A free, browser-based image-to-PDF converter. Upload JPG, PNG, or WEBP images, arrange pages, customize the output, and download one PDF. Files are processed locally in your browser.
## Features
- Multiple JPG, PNG, and WEBP images
- Drag-and-drop upload and page reordering
- Remove individual images or clear all
- Custom PDF filename (`xyz` becomes `xyz.pdf`)
- A4, A3, Letter, Legal, and original-image page sizes
- Portrait, landscape, and automatic orientation
- Fit, fill, and original-size placement modes
- Adjustable margins and image quality
- Responsive layout and dark mode
- Local browser processing; no image upload or account required

## Notes
- PDF generation uses jsPDF from cdnjs. If the CDN is unavailable, reconnect and refresh the page.
- Very large images can use substantial device memory. If conversion fails on a phone, try fewer images or a lower quality setting.
- `Fill page` may crop image edges by design. `Fit to page` preserves the full image without cropping.
